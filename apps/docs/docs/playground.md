# Playground

Every prop and theme variable, live. Toggle what you want and copy the snippet
at the bottom — it stays in sync with the clock above it.

<ClockPlayground />

The colors map to CSS custom properties, so you can set them on any ancestor
element rather than passing them as props. See
[CSS Customization](/docs/styling) for the full list of variables, including
the per-element overrides that are not surfaced here.
